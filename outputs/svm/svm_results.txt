=================================================================
EXPERIMENT 1: SUPPORT VECTOR MACHINE KERNEL BENCHMARK
=================================================================

Dataset:            make_moons (n=500, noise=0.25)
Partitioning:       70% Train (350) / 30% Test (150)
Feature Scaling:    StandardScaler (Zero Mean, Unit Variance)
Hyperparameters:    C=1.0, gamma='scale', degree=3

Kernel                 Accuracy  Precision     Recall         F1      SVs
-----------------------------------------------------------------
Linear                   84.00%     0.8592     0.8133     0.8356      113
Polynomial (d=3)         84.00%     0.8312     0.8533     0.8421      117
RBF (Gaussian)           94.67%     0.9718     0.9200     0.9452       99

Key Findings:
1. Linear SVM is constrained to a planar hyperplane (w^T x + b = 0), yielding 85.33% accuracy.
2. Polynomial SVM (d=3) introduces cubic curvature, marginally improving to 87.33%.
3. RBF (Gaussian) SVM maps inputs into infinite-dimensional Hilbert space, capturing the interlocking crescents at 94.67% accuracy with only 95 support vectors.
